# استفتاء المعلّم المفضّل

موقع تصويت مدرسي: الطالب يصوّر الباركود بهاتفه، يكتب اسم معلّمه المفضّل، والمدير يرى الترتيب والنِّسب في لوحة النتائج.

## التشغيل

يحتاج Node.js 22.13 أو أحدث.

```bash
npm install
npm start
```

- صفحة التصويت: `http://localhost:3000`
- لوحة النتائج: `http://localhost:3000/admin` — أول زيارة تطلب منك إنشاء كلمة مرور المدير.

## خطوات الاستخدام

1. افتح `/admin` وأنشئ كلمة المرور.
2. تبويب **المعلّمون**: الصق أسماء المعلّمين الكاملة، اسم في كل سطر.
3. تبويب **الباركود**: ضع رابط الموقع المنشور واطبع الملصق.
4. تبويب **النتائج** يتحدّث تلقائياً كل خمس ثوانٍ.
5. تبويب **المراجعة**: الأسماء التي لم يتأكّد النظام من صاحبها تنتظر قرارك هنا.

## كيف تُطابَق الأسماء

المنطق في `lib/names.js` واختباراته في `test/names.test.js` (`npm test`).

- **توحيد الكتابة**: حذف التشكيل والألقاب (أ.، الأستاذ، د.…)، توحيد الهمزات والتاء المربوطة والألف المقصورة، «عبد الله» = «عبدالله»، «العنزي» = «عنزي».
- **الاسم الناقص**: «محمد العنزي» يُحسب لـ«محمد صالح العنزي» ما دام لا يوجد معلّم آخر يحتمله.
- **الخطأ الإملائي**: «العنيزي» = «العنزي» (فرق حرف واحد في كلمة طويلة).
- **لا خلط بين الأسماء المختلفة**: «محمد» و«محمود» و«أحمد» و«حمد» تبقى أسماء مختلفة.
- **الاسم الملتبس**: إن احتمل الاسم أكثر من معلّم يُسأل الطالب «أيّ معلّم تقصد؟»، وإن لم يختر ذهب الصوت إلى تبويب المراجعة ولا يُحسب لأحد حتى تقرّر.
- **الشفافية**: تحت كل معلّم في النتائج قائمة بالصيغ التي كُتب بها اسمه، ويمكنك فصل أي صيغة حُسبت له خطأً.

## النشر

الموقع خادم Node واحد وقاعدة بيانات SQLite في مجلد `data/`. انشره على أي استضافة تدعم Node أو Docker **مع قرص دائم** لمجلد البيانات، وإلا ضاعت الأصوات عند إعادة التشغيل.

| المتغيّر | الوظيفة |
| --- | --- |
| `PORT` | المنفذ (الافتراضي 3000) |
| `DATA_DIR` | مجلد قاعدة البيانات (الافتراضي `./data`) |
| `ADMIN_PASSWORD` | اختياري: يثبّت كلمة مرور المدير من الخادم |

```bash
docker build -t teacher-vote .
docker run -p 3000:3000 -v teacher-vote-data:/data teacher-vote
```
